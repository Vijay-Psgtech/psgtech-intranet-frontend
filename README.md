# PSG TECH INTRANET DOCUMENTATION SITE - Frontend

A React-based frontend for the PSG Tech Intranet Documentation Site. This project is built using React, a popular JavaScript library for building user interfaces.

## 🛠️ Tech Stack

- **Frontend:** React 19.2.0, Vite 7.2.2, Tailwind CSS 4.1.17
- **Animations:** Framer Motion 12.23.24
- **Icons:** Lucide React 0.554.0
- **Routing:** React Router DOM 7.9.6
- **Deployment:** Docker + Nginx (SPA routing)
